# Stunnz Dynamic Tracker

**A custom WordPress plugin that enhances the WP Cargo shipment tracking experience with a more dynamic, interactive front end.**

## Overview

Stunnz Dynamic Tracker is a custom WordPress plugin developed to work alongside WP Cargo. Its purpose is to improve how customers view and follow their shipments by presenting tracking information through an animated map and a more engaging tracking interface.

Rather than displaying only basic shipment details, the plugin provides a more visual way for customers to follow shipment progress and understand the journey towards the final destination.

## Key Features

- **Animated shipment tracking:** Displays an animated shipment marker moving across the map to represent the shipment journey.
- **Google Maps integration:** Provides a more interactive and visually engaging map-based tracking experience.
- **Estimated delivery countdown:** Displays a countdown indicating the estimated time remaining until the shipment reaches its destination.
- **Shipment details:** Presents additional information about the package being tracked.
- **Freight type display:** Shows the transport method used, including road, sea, or air freight.
- **Enhanced tracking interface:** Improves the front-end presentation of shipment information for customers.
- **WP Cargo integration:** Works alongside WP Cargo to enhance its existing shipment tracking experience.

## Technologies

- WordPress
- PHP
- Google Maps integration
- WP Cargo integration
- JavaScript and front-end animation, where implemented

## Project Purpose

The goal of Stunnz Dynamic Tracker is to make shipment tracking more informative, interactive, and engaging for customers by combining shipment details, estimated delivery information, freight type, and animated map visualisation in one interface.

## Installation

Install and activate WP Cargo and configure it according to its requirements. Install Stunnz Dynamic Tracker and follow the plugin's setup instructions.

Google Maps functionality may require a valid API key and appropriate configuration.

## Notes

This plugin is designed to enhance the customer-facing tracking experience provided by WP Cargo. Map movement and estimated delivery information depend on the plugin's implementation and the tracking data available.
